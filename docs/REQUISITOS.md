# Requisitos iniciais — AnimeDex

**Escopo identificado:** Addon Stremio de catálogo de animes com Supabase/Deno e worker opcional de scraping.

## Requisitos a confirmar
- RF-01: Expor operação principal para o usuário/consumidor previsto.
- RF-02: Validar dados de entrada e lidar com falhas externas.
- RF-03: Manter compatibilidade com formatos e contratos existentes.
- RNF-01: Separar regras de negócio de infraestrutura.
- RNF-02: Documentar configuração e dependências externas sem segredos.
- RNF-03: Incluir testes unitários, de integração e casos negativos.

**Atenção:** Não considerar fontes de streaming e scraping garantidas; respeitar direitos autorais e termos das fontes.

Esta especificação é uma base inicial; não implica que todos os casos estejam implementados.
