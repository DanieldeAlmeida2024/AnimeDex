# AnimeDex

AnimeDex é um addon para a plataforma Stremio, focado em facilitar o acesso e a organização de animes. Desenvolvido em TypeScript, o projeto integra a API da plataforma Stremio utilizando as bibliotecas oficiais para garantir máxima compatibilidade e facilidade de manutenção.

## ✨ Funcionalidades

- Consulta e exibição de animes com informações detalhadas.
- Integração com a API do Stremio para busca e exibição de conteúdo.
- Organização personalizada para sua biblioteca de animes.
- Deploy automatizado via Vercel.

## 🚀 Como executar

### Pré-requisitos

- [Node.js](https://nodejs.org/)
- [npm](https://www.npmjs.com/) ou [yarn](https://yarnpkg.com/)
- [Git](https://git-scm.com/)

### Instalação

1. Clone o repositório:
   ```sh
   git clone https://github.com/DanieldeAlmeida2024/AnimeDex.git
   ```
2. Acesse a pasta do projeto:
   ```sh
   cd AnimeDex
   ```
3. Instale as dependências:
   ```sh
   npm install
   # ou
   yarn install
   ```

### Desenvolvimento

Para rodar o projeto em modo de desenvolvimento:
```sh
npm run dev
# ou
yarn dev
```

### Build para produção

```sh
npm run build
# ou
yarn build
```

## 📦 Deploy

O projeto conta com deploy automatizado via [Vercel](https://vercel.com/), facilitando a publicação e atualizações do addon.

Acesse a versão mais recente em:  
[https://anime-dex-nine-phi.vercel.app](https://anime-dex-nine-phi.vercel.app)

## 🛠️ Tecnologias utilizadas

- **TypeScript** — linguagem principal
- **Stremio Addon SDK** — integração com Stremio
- **Node.js** — ambiente de execução
- **Vercel** — deploy automatizado
